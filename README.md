# Fish Eat Fish – JavaFX 2D Game

## Overview
Fish Eat Fish is a 2D arcade-style game developed using JavaFX. The player controls a fish that must eat smaller fish to grow while avoiding larger enemies. The game demonstrates core concepts of object-oriented programming and real-time game mechanics.

This project was developed as part of a university assignment to apply Java programming, UI design, and game development principles.

---

## Features
- Real-time player movement controls
- Collision detection between game objects
- Score tracking system
- Dynamic enemy behavior (fish interactions)
- Game state management (win/lose conditions)
- Interactive JavaFX-based graphical user interface

---

## Tech Stack
- Programming Language: Java  
- Framework: JavaFX  
- Programming Paradigm: Object-Oriented Programming (OOP)
